❓ Frequently Asked Questions

Quick answers to common questions about TaskFlow.

What is TaskFlow? ▼
TaskFlow is a lightweight, browser-based task management tool built to help individuals and small teams track tasks from creation to completion. It runs entirely in the browser with no backend required.
How do I add a new task? ▼
Click on Add Task in the sidebar. Fill in the task title, description, due date, and select a priority (High / Medium / Low). Then click Save Task.
Can I filter tasks by status? ▼
Yes! Head to the Task List page and use the filter buttons — All, Pending, or Completed — to view only the tasks matching that status.
How do I mark a task as complete? ▼
Navigate to the Task Detail page by clicking View on any task in the list. Then click the Mark as Complete button. The status badge will update immediately.
How do I delete a task? ▼
Open the task from the Task List, then click the Delete Task button on the Task Detail page. You will be asked to confirm before the task is removed permanently.
How is TaskFlow deployed? ▼
TaskFlow is containerised using Docker (nginx-based) and deployed automatically via a GitHub Actions CD pipeline to Render. Every time a Pull Request is merged into the develop branch, the CD workflow triggers a fresh deployment — no manual steps required.
Where can I get more help? ▼
Visit the About page for a usage guide, or go to the Contact page to send a message to the TaskFlow team.
