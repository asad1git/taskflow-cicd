What is TaskFlow and how do you use it?

What is TaskFlow?

TaskFlow is a lightweight, browser-based task management application designed for individuals and small teams. It helps you track work items from creation to completion without any backend — pure HTML, CSS, and a shared style system.

This application was built as part of a DevOps CI/CD pipeline assignment, demonstrating how a team can collaboratively build and deploy a containerised web app using GitHub Actions, Docker, and Render.

📖 How to Use
Step 1
Add a Task — Navigate to Add Task and fill in the title, description, due date, and priority. Click Save Task.
Step 2
View Your Tasks — Go to Task List to see all tasks. Use filter buttons (All / Pending / Completed) to narrow the view.
Step 3
Inspect a Task — Click View on any task row to open its detail page, where you can read the full description.
Step 4
Complete or Delete — On the detail page, mark a task as complete or delete it permanently using the action buttons.
Step 5
Dashboard — Return to the Dashboard at any time to see summary counts and recent task activity.
